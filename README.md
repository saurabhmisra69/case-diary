# Case Diary

Advocate's case diary: matters, hearing dates, cause list, fees and deadlines, linked to OneDrive case folders. Works on phone and computer and can be installed as an app.

- App: https://saurabhmisra69.github.io/case-diary/
- This repository holds the app code only. All case data is stored in the signed-in user's own OneDrive (`OneDrive › Case Diary`), never here.
